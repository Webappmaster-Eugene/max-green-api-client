# Max — закрытый React-клиент GREEN-API

[Сайт](https://max.nadtocheev.ru) · [Руководство пользователя](docs/USER_GUIDE.md) · [Архитектура](docs/ARCHITECTURE.md) · [Безопасность](docs/SECURITY.md) · [Запуск и Dokploy](docs/DEPLOYMENT.md) · [HTTP API](docs/API.md)

Личные пользователи без публичной регистрации. Вход по логину и паролю, JWT в
HttpOnly-cookie, выдача/отзыв доступа администратором. Подключение MAX доступно
только после входа; переписка и вложения изолированы по пользователю.

Интерфейс на **React 19, Mantine и Feature-Sliced Design**: существующие чаты и
контакты, история, поиск, текст и файлы, цитаты, пересылка, редактирование,
подтверждение удаления, реакции, отметка прочтения и сохранение загруженной истории.
На телефоне список и диалог открываются отдельно, на компьютере рядом.

Zod-контракты находятся в `contracts/`, типы — в `types/` и отдельных UI-файлах.
Контракты проверяются на сервере, в браузере и при получении данных провайдера.
В production source нет комментариев или explicit any; границы FSD проверяются тестом.

## Быстрый старт

Полная пошаговая инструкция: [локальный запуск, настройка GREEN-API и проверка переписки](docs/DEPLOYMENT.md#локальная-установка).

```sh
npm ci
npm run auth:setup
npm run build
npm run start:local
```

Открыть http://127.0.0.1:18792. Начальные приватные реквизиты — в
`.admin-credentials`, настройки — в `.env.local`. Эти файлы не перезаписываются,
не коммитятся и не включаются в Docker context. После входа подключите инстанс MAX
реквизитами из GREEN-API. Для разработки: `npm run dev` и `npm run dev:ui`,
интерфейс на http://127.0.0.1:5174.

## Проверки

```sh
npm run format:check
npm run smoke
npm test
npm run test:ui
npm run build
npx playwright install chromium
npm run test:e2e
```

Тесты проверяют безопасность входа, ownership, отзыв доступа, файлы и критичные
операции. E2E использует настоящий локальный сервер авторизации и подменённый
MAX API, без реальных сообщений и аккаунтов. CI запускает те же проверки.

## Развёртывание

Dockerfile, порт 3000, HTTPS, `PUBLIC_ORIGIN`, обязательный `AUTH_JWT_SECRET`,
первый администратор через `ADMIN_LOGIN`/`ADMIN_PASSWORD_HASH`. Persistent volume
на `/app/data`, **одна реплика**. Настройки и восстановление —
[в инструкции](docs/DEPLOYMENT.md). Telegram, PostgreSQL и Redis не требуются.

Реквизиты MAX и сессии сайта сохраняются в зашифрованном хранилище в `DATA_DIR`;
перезапуск не требует повторного подключения. После явного отключения MAX вход
доступен по одному ключу GREEN-API. История загружается из провайдера и хранится
в RAM. Для одного инстанса используйте один клиент очереди: сайт и Mini App
Советника имеют независимые сессии. История ограничена провайдером тремя месяцами
и 5000 событиями; файл — 10 МБ. Звонки, управление группами, фоновые push,
постоянный архив, MFA и антивирус не реализованы.

Это самостоятельный репозиторий веб-клиента. Он не содержит личной переписки,
ключей, конфигов Dokploy или остальной инфраструктуры Советника.
