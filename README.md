Max - закрытый веб-клиент для переписки через GREEN-API.

[Открыть сайт](https://max.nadtocheev.ru). Для входа нужны логин и пароль,
которые выдаёт администратор. Публичной регистрации нет.

Можно читать существующие чаты, выбирать контакты, отправлять текст и файлы,
отвечать с цитатой, пересылать сообщения, ставить реакции, редактировать
и удалять свои сообщения. Есть поиск, история, светлая и тёмная темы.
На компьютере список чатов и переписка находятся рядом. На телефоне они
открываются по очереди.

Чтобы запустить клиент у себя, нужны Node.js 22.12 или новее, npm и Git.
Telegram, PostgreSQL и Redis для этого приложения не нужны.

```sh
git clone https://github.com/Webappmaster-Eugene/max-green-api-client.git
cd max-green-api-client
npm ci
npm run auth:setup
npm run build
npm run start:local
```

Откройте http://127.0.0.1:18792. Логин и пароль находятся в локальном файле
`.admin-credentials`. Настройки сервера находятся в `.env.local`.
Не публикуйте эти файлы. После входа подключите свой инстанс MAX из GREEN-API.
Инстанс - это подключение аккаунта, созданное в кабинете провайдера.

[Инструкция запуска и настройки](docs/DEPLOYMENT.md) объясняет каждый шаг,
подключение GREEN-API и типичные ошибки. [Руководство пользователя](docs/USER_GUIDE.md)
описывает работу с чатами. Устройство кода описано в [ARCHITECTURE.md](docs/ARCHITECTURE.md),
защита доступа - в [SECURITY.md](docs/SECURITY.md), запросы сервера - в [API.md](docs/API.md).
Результаты проверки ТЗ находятся в [ACCEPTANCE.md](docs/ACCEPTANCE.md).

Интерфейс написан на React и Mantine. Код разделён по FSD: страницы, крупные
блоки, действия пользователя и общие компоненты лежат отдельно. Zod проверяет
данные в `contracts/`. Типы находятся в `types/` и отдельных файлах интерфейса.

Подключение MAX сохраняется на сервере в зашифрованном виде. Перезапуск
не требует повторного ввода реквизитов. После нажатия «Отключить MAX»
для повторного входа достаточно ключа GREEN-API. История загружается
из провайдера и не хранится как постоянный архив.

Один инстанс должен иметь одного потребителя очереди уведомлений.
Если сайт и Mini App одновременно читают одну очередь, часть ответов
может попасть только в один из них. Звонки, создание групп, запись голоса
и уведомления при закрытом сайте не реализованы. Размер файла ограничен 10 МБ.

Проверки запускаются так:

```sh
npm run format:check
npm run smoke
npm test
npm run test:ui
npm run build
npx playwright install chromium
npm run test:e2e
```

Браузерные тесты используют локальный сервер входа и подменённый MAX API.
Они не отправляют сообщения реальным людям. CI запускает проверки после push.

Для размещения в Dokploy используются Dockerfile, порт 3000 и HTTPS.
Нужны постоянный каталог `/app/data` и одна копия приложения.
Подробности есть в инструкции запуска. Этот репозиторий содержит только
веб-клиент, без личной переписки и настроек инфраструктуры Советника.
