# Max: руководство пользователя

Сайт: [max.nadtocheev.ru](https://max.nadtocheev.ru). Это закрытый клиент MAX
через GREEN-API. Он работает в браузере компьютера или телефона.

## Получить доступ и войти

Публичной регистрации нет. Администратор сайта выдаёт личный логин и пароль.
Откройте сайт, введите их и нажмите **Войти**. Это пароль сайта, а не пароль MAX
и не ключ GREEN-API. Реквизиты разных сервисов не взаимозаменяемы.

Пароль сайта содержит от 12 до 128 символов. В меню **Аккаунт и настройки →
Пароль сайта** можно изменить его. Потребуются текущий пароль и два одинаковых
ввода нового. После изменения нужно войти заново на всех устройствах.

Вход действует восемь часов. При завершении сессии сайт покажет форму входа.
После перезапуска сервера нужно войти заново. Если пароль забыт, попросите
администратора сбросить его.

## Подготовить аккаунт MAX

1. Войдите в [кабинет GREEN-API](https://console.green-api.com/).
2. Создайте или выберите инстанс именно **MAX**. Инстансы WhatsApp и Telegram
   для этого клиента не подходят.
3. Авторизуйте аккаунт способом, который предлагает кабинет. Подключение
   подтверждает владелец MAX-аккаунта. При использовании аккаунта другого человека
   необходимо его разрешение на чтение переписки и отправку сообщений от его имени.
4. Оставьте поле `webhookUrl` пустым. Включите уведомления о входящих сообщениях
   и файлах, исходящих сообщениях с телефона и через API, статусах доставки,
   редактировании и удалении. Настройки могут применяться с задержкой.
5. Скопируйте `apiUrl`, `mediaUrl`, `idInstance` и `apiTokenInstance` из карточки
   инстанса. Не передавайте ключ в URL, общих чатах или публичных скриншотах.
6. Отключите этот инстанс в другом клиенте, включая Mini App Советника. Один
   инстанс должен иметь одного потребителя очереди уведомлений. Иначе разные
   клиенты будут получать разные части ответов.

Актуальная процедура авторизации аккаунта описана в
[инструкции GREEN-API](https://green-api.com/v3/docs/before-start/).

## Подключить MAX на сайте

После входа заполните форму **Подключите аккаунт MAX**:

| Поле             | Что вводить                                             |
| ---------------- | ------------------------------------------------------- |
| Адрес API        | `apiUrl` из кабинета, HTTPS-адрес сервера GREEN-API     |
| Адрес для файлов | `mediaUrl` из кабинета; требуется для отправки вложений |
| Номер инстанса   | `idInstance`                                            |
| Ключ GREEN-API   | `apiTokenInstance`                                      |

Подтвердите разрешение владельца и нажмите **Подключить MAX**. Сервер проверит
авторизацию и настройки инстанса и загрузит существующие чаты и контакты.
Ключ после успешного подключения очищается из формы. Сервер хранит его только
в оперативной памяти до отключения, выхода, перезапуска или истечения восьми часов.

Для отправки файлов укажите адрес `mediaUrl` точно как в кабинете. Если оба
адреса совпадают, оставьте включённым переключатель совпадения адресов. Для MAX он
может совпадать с `apiUrl`, например `https://3100.api.green-api.com`. Менять
`api` на `media` в адресе не нужно.
Если он не был введён, отключите MAX и подключите заново с этим полем.

В интерфейсе показывается подключённый аккаунт. Получатель видит сообщения
от этого MAX-аккаунта. Вход на сайт не создаёт новую личность отправителя.

## Чаты и контакты

На компьютере список находится слева, переписка справа. На телефоне открытие
диалога заменяет список; стрелка **Назад к чатам** возвращает к нему.

- **Чаты** показывают существующие диалоги, время последнего загруженного события,
  текст последнего сообщения и счётчик новых сообщений в клиенте.
- **Контакты** позволяют открыть переписку без повторного ввода номера. Номер может
  быть скрыт владельцем; это не мешает отправке по идентификатору контакта.
- Поле поиска ищет по имени, номеру и ID в загруженном списке.
- Кнопка обновления повторно запрашивает список у GREEN-API. Новые контакты могут
  появляться с задержкой в несколько минут.
- Для нового получателя нажмите **Новый чат**, введите номер РФ `+7…` или Беларуси
  `+375…`, затем **Открыть чат**. Поиск зависит от приватности получателя и тарифа.

При открытии загружаются последние 100 событий. Кнопка **Загрузить более ранние
сообщения** увеличивает выборку на 100, до 5000. История GREEN-API ограничена
последними тремя месяцами. Полный архив MAX старше этого срока сайт не обещает.

В меню **Действия с чатом** доступны обновление истории, отметка прочтения
и сохранение загруженной истории в текстовый файл. Сохранение включает только
сообщения, которые уже загружены в этот клиент.

Поиск в истории выполняется по загруженным сообщениям, именам отправителей
и названиям вложений. Для поиска более ранних сообщений сначала загрузите их.

## Отправка текста и ответы

Выберите чат, напишите текст и нажмите кнопку отправки. На компьютере `Enter`
отправляет сообщение, `Shift + Enter` добавляет новую строку. На телефоне сообщение
отправляется кнопкой. Текст ограничен 4000 символами.

Черновики текста и выбранные цитаты разделены по чатам и остаются в памяти вкладки.
Они не сохраняются после обновления страницы или выхода. Между отправками
действует интервал три секунды.

Чтобы ответить с цитатой, откройте меню нужного сообщения и выберите **Ответить**.
Цитата появится над полем ввода. Крестик отменяет ответ. Цитировать можно сообщение
того же чата, известное GREEN-API.

### Что означают статусы

| Статус        | Значение                                               |
| ------------- | ------------------------------------------------------ |
| В очереди     | GREEN-API принял запрос; доставка пока не подтверждена |
| Отправлено    | Провайдер сообщил об отправке                          |
| Доставлено    | Получено уведомление о доставке                        |
| Прочитано     | Получено уведомление о прочтении                       |
| Не отправлено | Провайдер сообщил об ошибке                            |

Статусы поступают из уведомлений. Если сеть оборвалась во время отправки и появился
текст **Результат отправки неизвестен**, сначала проверьте переписку в MAX.
Сайт автоматически не отправляет такое сообщение повторно. Повтор запроса с тем же
содержимым в текущей сессии использует прежний идентификатор попытки.

Ответы приходят при открытой видимой вкладке. В скрытой вкладке опрос приостановлен.
При временном сбое он повторяется с увеличением интервала. Фоновых уведомлений
при закрытом сайте нет.

## Фото и файлы

Нажмите **Прикрепить файл**, выберите файл и при необходимости добавьте подпись.
Имя и размер появятся над полем ввода; крестик убирает вложение. При переходе
в другой чат выбранный файл сбрасывается, текстовый черновик сохраняется.

Ограничение клиента — 10 МБ. Разрешены JPG, JPEG, PNG, WebP, GIF, PDF, TXT, CSV,
ZIP, DOC/DOCX, XLS/XLSX, PPT/PPTX, MP4, WebM, MP3, WAV и OGG. SVG, HTML,
скрипты и исполняемые файлы не принимаются. Квоты и ограничения MAX действуют
дополнительно.

Входящие вложения отображаются в истории. **Скачать** получает файл через
защищённый серверный маршрут. Для поддерживаемых растровых фото есть
**Посмотреть фото**. Для видео и аудио доступно скачивание, встроенной записи
голосовых сообщений нет.

Если ссылка пока не появилась, обновите историю. Срок ссылок на стороне GREEN-API
ограничен; просроченные или недоступные вложения клиент скачать не сможет.

## Действия с сообщениями

Откройте меню с тремя точками возле сообщения:

- **Редактировать** — доступно для отправленного исходящего текста в течение
  24 часов. Измените текст и нажмите **Сохранить сообщение**. ID оригинального
  сообщения сохраняется. Вложения этим действием не редактируются.
- **Удалить** — доступно для отправленных исходящих сообщений. В диалоге
  подтверждения можно выбрать удаление только у себя. По умолчанию запрос удаляет
  сообщение у всех участников. До подтверждения запрос провайдеру не отправляется.
- **Переслать** — выберите получателя из чатов или контактов и подтвердите.
  Исходное сообщение должно быть известно GREEN-API.
- **Реакция** — выберите один из предложенных emoji. В клиенте отображается
  ваша последняя поставленная реакция. Набор может ограничиваться MAX.

События редактирования и удаления с телефона также обрабатываются, если включены
соответствующие уведомления. Просмотр групповой переписки и отправка в неё
поддерживаются; управление участниками, создание групп и звонки не реализованы.

## Отключить MAX или выйти

**Аккаунт и настройки → Отключить MAX** удаляет ключ и временную историю из памяти
сайта. Учётная запись сайта остаётся открытой. Это не разлогинивает инстанс GREEN-API.

**Выйти из сайта** отзывает текущую JWT-сессию и отключает подключённый MAX.
Для повторного входа нужны пароль сайта и затем реквизиты GREEN-API. При полном
отзыве доступа к MAX дополнительно завершите устройство в MAX/кабинете GREEN-API
и при необходимости смените ключ провайдера.

## Для администратора

Откройте **Аккаунт и настройки → Управление доступом**:

1. Введите логин нового пользователя, временный пароль и роль.
2. Нажмите **Создать пользователя** и передайте реквизиты лично.
3. Попросите пользователя изменить временный пароль после входа.

Пользователь может подключать только свой MAX-инстанс в рамках своей учётной записи.
Роль администратора дополнительно даёт управление доступом к сайту, но не открывает
переписку других пользователей.

**Отключить доступ** требует подтверждения, завершает сессии пользователя и удаляет
его подключение MAX из памяти. **Открыть доступ** позволяет войти снова.
Сброс пароля также завершает старые сессии. Нельзя отключить себя или последнего
активного администратора.

## Если что-то не работает

| Симптом                         | Действие                                                     |
| ------------------------------- | ------------------------------------------------------------ |
| Неверный логин или пароль       | Проверьте реквизиты сайта или обратитесь к администратору    |
| Слишком много запросов на вход  | Подождите; не отправляйте повторные запросы подряд           |
| Инстанс не авторизован          | Проверьте состояние MAX в кабинете GREEN-API                 |
| Требуются настройки уведомлений | Очистите webhookUrl и включите нужные уведомления            |
| Контакты пусты                  | Подождите синхронизацию GREEN-API и обновите список          |
| Часть ответов исчезает          | Проверьте, что этот инстанс не читает другой клиент          |
| Нельзя прикрепить файл          | Укажите mediaUrl при подключении; проверьте формат и размер  |
| Нельзя изменить сообщение       | Проверьте, что это исходящий отправленный текст моложе суток |
| Пересылка не доставляется       | Исходное сообщение должно быть известно системе GREEN-API    |
| Сессия завершена                | Войдите и подключите MAX заново                              |

Тариф MAX Developer ограничивает взаимодействие тремя чатами. Номер, затем ID
одного получателя могут влиять на квоту; для существующих контактов клиент использует
канонический ID. За тарифными ограничениями следите в кабинете GREEN-API.

Фотографии можно открыть в окне просмотра, видео и аудио — воспроизвести.
Файл скачивается через защищённый сервер. Поддержка кодека зависит от браузера;
если видео не воспроизводится, скачайте его. Кнопка ранней истории появляется
только при наличии дополнительных сообщений в ответе GREEN-API.

Код 429 означает временное ограничение частоты запросов. Безопасные запросы
подключения и чтения повторяются с задержкой, отправка автоматически не
повторяется. Код 466 означает исчерпание квоты; получение обновлений приостанавливается
до нажатия «Проверить после изменения настроек». Код 469 показывается отдельно.
